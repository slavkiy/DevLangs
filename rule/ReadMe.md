# Правила сети [@DevLengs](https://t.me/@DevLengs)

## 1. Общие положения

* Все участники обязаны соблюдать уважительное и профессиональное общение.
* Основной язык общения - русский (если иное не указано для конкретного чата).
* Администрация оставляет за собой право изменять правила и принимать решения в спорных ситуациях.

## 2. Тематика чатов

* Каждый чат имеет свою тематику. Публикуйте сообщения только по теме.
* Для вопросов, не относящихся к теме, используйте соответствующие ветки в группе или используйте оффтоп чат.

## 3. Общение

* Запрещены оскорбления, травля, дискриминация и провокации.
* Не допускаются токсичное поведение, флуд, спам и намеренный оффтоп.
* Конструктивная критика приветствуется, если она выражена корректно.

## 4. Вопросы и помощь

* Перед тем как задать вопрос, воспользуйтесь поиском по чату.
* При обращении за помощью:

  * кратко опишите проблему;
  * укажите используемые технологии и версии;
  * приложите код, логи или скриншоты при необходимости;
  * сообщите, что уже пробовали сделать самостоятельно.

## 5. Код и технические материалы

* Используйте форматирование кода при публикации фрагментов.
* Не отправляйте большие объемы кода одним сообщением — используйте GitHub Gist, Pastebin или аналогичные сервисы.
* Не публикуйте вредоносный код, эксплойты или инструкции по незаконной деятельности.

## 6. Реклама и самореклама

* Любая реклама, продвижение продуктов, услуг, каналов, вакансий и мероприятий допускается только в специально предназначенных чатах или с разрешения администрации.
* Запрещены массовые рассылки и навязчивое продвижение.

## 7. Конфиденциальность

* Не публикуйте персональные данные без согласия владельца.
* Не распространяйте внутреннюю информацию сообщества без разрешения.

## 8. Безопасность

* Запрещены мошенничество, фишинг, распространение вредоносного ПО и любых материалов, нарушающих законодательство.
* Не публикуйте токены, пароли, API-ключи и другие конфиденциальные данные.

## 9. Действия администрации

Администрация может применять следующие меры:

* предупреждение;
* удаление сообщений;
* временное ограничение доступа;
* бессрочную блокировку за грубые или систематические нарушения.
